# PyTaskSyn 基线调研与复现说明

## 1. 项目简介
PyTaskSyn 是一个基于大模型的编程任务自动生成系统，核心能力是「任务生成 + 自验证」闭环，通过内置验证器对生成的代码题做自动化校验，提升出题质量。

原仓库地址：https://github.com/...

## 2. 基线核心流程
1. **任务生成**：根据知识点、难度生成结构化编程题，包含题干、示例、测试用例
2. **自验证**：Schema 校验 + 测试用例格式校验 + 可运行性检查
3. **迭代优化**：对未通过验证的任务进行修正，循环直到通过

## 3. 基线优势
- 成熟的「生成-验证」闭环思路，可直接复用到本项目自动验证模块
- 结构化输出设计，题目字段规范，适合后续流水线处理
- 验证逻辑分层，从基础格式到语义逐步校验，效率较高

## 4. 基线局限性（本项目创新切入点）
| 局限点 | 本项目改进方向 |
|--------|----------------|
| 仅支持编程题，无选择题、判断题等题型 | 扩展支持选择题、判断题，覆盖更多试卷场景 |
| 只有单题粒度，无试卷级结构约束 | 引入试卷蓝图，按题型、难度、知识点分布整卷生成 |
| 无干扰项设计、误解标签体系 | 结合学科误解标签，生成高质量干扰选项 |
| 无难度量化校准机制 | 引入 IRT + 模拟学生，冷启动估算题目难度与区分度 |
| 无教师介入、人工审核链路 | 增加教师蓝图编辑、题目审核反馈回路 |
| 无约束组卷能力 | 实现多约束组卷算法，按蓝图从题库中选题成卷 |

## 5. 本地复现说明
### 环境依赖
- Python 3.10+
- 依赖已统一纳入项目 requirements.txt

### 运行方式
在项目根目录执行：
`ash
python baseline/pytasksyn/run_demo.py
`

### 输出说明

- 运行后自动生成 5 道编程任务样例
- 结果保存在 aseline/pytasksyn/output/week1_samples.json
- 未配置 API 密钥时自动使用离线模拟数据，流程可正常跑通
- 补充 .env 密钥后可生成真实大模型输出结果

## 6. 复现范围说明

本周仅复现「生成 + 基础验证」最小链路，用于理解基线逻辑、验证自研 LLM 客户端可用性；完整验证器、迭代优化等能力后续随项目迭代逐步扩展。
