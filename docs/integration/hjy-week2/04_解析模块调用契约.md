# 04 样例卷解析模块调用契约

## 1. 当前状态

样例卷解析已经完成的是“离线批量解析”，主数据已经冻结。

本周给后端和 Agent 使用的是“统一调用契约”，不是继续重复写解析脚本。

## 2. 输入约定

解析模块支持两种入口：

### A. 已冻结题库入口

适合直接复用 408 真题数据，不需要重新解析网页或文件。

```python
from pathlib import Path

def load_frozen_questions(
    path: str | Path = r"E:\Codex\2026-10-14\new-chat\outputs_fixed\408_data_v2\408_questions_v2_4_1.jsonl"
) -> list[dict]:
    ...
```

输入：

| 参数 | 类型 | 说明 |
|---|---|---|
| `path` | `str` / `Path` | JSONL 文件路径 |

输出：

| 字段 | 类型 | 说明 |
|---|---|---|
| `list[dict]` | list | 每一项是一个完整题目对象 |

### B. 文本解析入口

适合后续接入上传的样例卷文本。

```python
def parse_exam_text(
    exam_text: str,
    subject: str = "数据结构"
) -> dict:
    ...
```

输入：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `exam_text` | string | 是 | 样例卷纯文本 |
| `subject` | string | 否 | 默认为 `数据结构` |

## 3. 输出结构

### 顶层返回

```json
{
  "questions": [],
  "shared_contexts": [],
  "stats": {},
  "warnings": []
}
```

### `questions[]`

每道题至少包含以下字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 题目唯一 ID |
| `year` | int | 年份 |
| `question_number` | int | 题号 |
| `question_type` | string | `单选题` 或 `综合应用题` |
| `subject` | string | 课程名 |
| `stem_html` | string | 题干 HTML |
| `stem_text` | string | 题干纯文本 |
| `options` | array | 选项数组 |
| `answer` | string | 正确答案 |
| `explanation_html` | string | 解析 HTML |
| `explanation_text` | string | 解析纯文本 |
| `tags` | array[string] | 原始标签 |
| `images` | array[string] | 图片路径 |
| `shared_context_id` | string | 共享材料 ID |
| `knowledge_point_ids` | array[string] | 规范知识点 ID |
| `knowledge_points` | array[object] | 规范知识点数组 |
| `source_url` | string | 来源 URL |
| `answer_available` | bool | 是否有答案 |

## 4. 调用示例

### 读取冻结题库

```python
import json
from pathlib import Path

def load_frozen_questions(path):
    questions = []
    with Path(path).open(encoding="utf-8") as f:
        for line in f:
            if line.strip():
                questions.append(json.loads(line))
    return questions
```

### 按课程筛选

```python
questions = load_frozen_questions("408_questions_v2_4_1.jsonl")
ds_questions = [q for q in questions if q["subject"] == "数据结构"]
```

### 只取单选题

```python
single_choice = [q for q in questions if q["question_type"] == "单选题"]
```

### 只取无图题

```python
no_image = [q for q in single_choice if not q.get("images")]
```

## 6. 错误约定

| 错误码 | 含义 | 处理建议 |
|---|---|---|
| 1001 | 参数校验失败 | 返回 422，检查 `exam_text` 或 `subject` |
| 1002 | 蓝图约束不满足 | 减少题量或调整知识点范围 |
| 2001 | 大模型调用失败 | 记录日志，重试 |
| 3001 | 题目验证不通过 | 不进入题库 |
| 4001 | 组卷失败 | 增加题目池或放宽约束 |
| 5000 | 系统内部错误 | 查看日志 |

4. 2026 年题不要用于调优。
