# 03 误解标签库结构与示例

## 1. 用途

误解标签用于告诉出题模型：

1. 学生容易在哪里想错。
2. 干扰项应该围绕哪种错误思维设计。
3. 解析里应该明确排除哪些错误理解。

它不是普通题目标签，也不是知识点标签。

## 2. 当前状态

目前 408 主数据里的 `tags` 是网页原始标签，例如：

- `排序算法`
- `虚拟页式管理`
- `中断IO`
- `处理机调度算法`

这些标签只能说明题目主题，不能直接当作误解标签使用。

本周已经基于 110 个锁定知识点生成一份完整误解标签库，供后续干扰项生成模块接入。

## 3. 文件建议

当前文件为：

```text
misconception_tags_v1.jsonl
misconception_tags_v1.csv
```

当前规模：110 条，覆盖全部 110 个锁定知识点。

编码：UTF-8  
格式：JSON Lines

## 4. 统一结构

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `tag_id` | string | 是 | 误解标签唯一 ID |
| `tag_name` | string | 是 | 误解标签中文短名 |
| `subject` | string | 是 | 所属课程 |
| `kp_id` | string | 是 | 关联规范知识点 ID |
| `kp_name` | string | 是 | 关联规范知识点名称 |
| `description` | string | 是 | 学生典型误解说明 |
| `wrong_pattern` | string | 是 | 错误作答或错误选项模式 |
| `evidence_question_id` | string | 否 | 有证据的真题 ID |
| `evidence_source` | string | 否 | 证据来源说明 |
| `generation_hint` | string | 是 | 出题和写干扰项时的建议 |
| `status` | string | 是 | `draft`、`reviewed`、`locked` |

## 6. 示例标签清单

| `tag_id` | `tag_name` | `subject` | `kp_id` | 典型误解 |
|---|---|---|---|---|
| `MIS-DS-001` | 时间复杂度分析复杂度误判 | 数据结构 | `KP-001` | 混用相近复杂度或漏掉边界约束 |
| `MIS-DS-006` | 栈的定义与操作顺序/边界误判 | 数据结构 | `KP-006` | 混淆后进先出、空栈边界或操作顺序 |
| `MIS-OS-002` | 进程与线程概念/条件混淆 | 操作系统 | `KP-054` | 混淆资源拥有、调度执行和共享范围 |
| `MIS-NET-021` | TCP连接管理概念/条件混淆 | 计算机网络 | `KP-098` | 混淆握手状态、序号确认和连接关闭条件 |

## 8. 生成建议

1. 一个干扰项只对应一种误解，不要叠加多个误解。
2. 干扰项应该看起来合理，但不能和正确答案等价。
3. 解析中应明确说明错误项对应的误解。
4. 如果没有精确误解标签，传空数组，由生成模块回退到通用干扰项策略；不要虚构标签 ID。
