# 01 样例卷解析后的实际输出字段清单

## 1. 数据来源与读取方式

- 冻结主数据：`outputs_fixed/408_data_v2/408_questions_v2_4_1.jsonl`
- 版本：`v2.4.1`
- 总题量：846
- 编码：UTF-8
- 读取方式：每行一个 JSON 对象

```python
import json

with open("408_questions_v2_4_1.jsonl", encoding="utf-8") as f:
    questions = [json.loads(line) for line in f if line.strip()]
```

## 2. 顶层字段清单

| 字段 | 类型 | 必有 | 说明 |
|---|---|---|---|
| `id` | string | 是 | 题目唯一 ID，格式 `408-年份-题号`，例如 `408-2009-001` |
| `year` | int | 是 | 真题年份 |
| `question_number` | int | 是 | 当年卷内题号 |
| `question_type` | string | 是 | 当前只有 `单选题`、`综合应用题` |
| `subject` | string | 是 | 课程名：`数据结构`、`计算机组成原理`、`操作系统`、`计算机网络` |
| `stem_html` | string | 是 | 原始题干 HTML，保留图片和结构 |
| `stem_text` | string | 是 | 纯文本题干，优先供生成与 RAG 使用 |
| `options` | array | 是 | 选择题选项数组；综合应用题可能为空 |
| `answer` | string | 是 | 正确答案；选择题为 `A/B/C/D` |
| `explanation_html` | string | 是 | 原始解析 HTML |
| `explanation_text` | string | 是 | 纯文本解析 |
| `tags` | array[string] | 是 | 网页原始标签，不作为统一知识点 ID 使用 |
| `images` | array[string] | 是 | 题目相关图片路径 |
| `shared_context_id` | string | 是 | 共享材料 ID；无共享材料时为空字符串 |
| `source_url` | string | 是 | 网页来源 |
| `source_title` | string | 是 | 来源标题 |
| `answer_available` | bool | 是 | 当前冻结版全部为 `true` |
| `review_status` | string | 是 | 当前冻结版全部为 `parsed_from_web_v2_1` |
| `in_gold_v1` | bool | 是 | 是否进入 Gold v1 |
| `cleaning_flags` | array[string] | 是 | 清洗标记 |
| `knowledge_points` | array[object] | 是 | 规范知识点数组 |
| `knowledge_point_ids` | array[string] | 是 | 规范知识点 ID 数组 |
| `dataset_version` | string | 是 | 数据版本 |

## 3. 嵌套字段

### `options[]`

| 字段 | 类型 | 说明 |
|---|---|---|
| `label` | string | 选项编号，通常为 `A/B/C/D` |
| `text` | string | 选项内容 |

### `knowledge_points[]`

| 字段 | 类型 | 说明 |
|---|---|---|
| `kp_id` | string | 统一知识点 ID，如 `KP-001` |
| `kp_name` | string | 统一知识点名称，如 `时间复杂度分析` |
| `source_tag` | string | 网页原始标签 |
| `mapping_type` | string | `existing` 或 `new` |

## 5. 与 `MCQuestion` 的映射建议

| 解析字段 | `MCQuestion` 字段 |
|---|---|
| `id` | `question_id` |
| `question_type` | `question_type` |
| `stem_text` | `stem` |
| `options` | `options` |
| `answer` | `answer` |
| `knowledge_points[0].kp_name` | `knowledge_point` |
| Gold 标注 `difficulty` | `difficulty` |
| Gold 标注 `bloom_level` | `bloom_level` |
| `primary_kp_id` 关联的误解标签 | `misconception_tag` |
| Gold 标注 `quality_notes` | `analysis` 或质量备注 |
| `source_url` | `source` |

难度映射建议：

| 原始难度 | `MCQuestion.difficulty` |
|---|---|
| 1、2 | `easy` |
| 3 | `medium` |
| 4、5 | `hard` |

## 7. 注意事项

1. 生成和检索优先使用 `stem_text`、`explanation_text`，不要直接解析 HTML。
2. 图片路径保留在 `images`，但一期生成尽量优先选择无图题。
3. `tags` 是网页原始标签，不应直接用于统一校验。
4. 统一知识点必须使用 `knowledge_points[].kp_id` 和 `kp_name`。
5. 2026 年题仍作为 blind test，不用于调优。
