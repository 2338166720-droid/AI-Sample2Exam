# 09 向量库构建报告

## 生成时间

2026-11-28

## 数据来源

- 语料：`408_seed_questions_v1_enriched.jsonl`
- 语料条数：100

## 输出文件

- `rag_corpus_v1.jsonl`
- `rag_tfidf_index_v1.joblib`

## 当前方案

1. 本周先用 TF-IDF 构建轻量检索库。
2. 文本字段包括：课程、知识点、题干、选项、解析。
3. 语料元数据带难度、Bloom 层级和误解标签。
4. `TfidfVectorizer` 使用字符级 2-4 gram，适配中文未分词文本。
5. 后续可以替换成语义向量模型，索引结构不变。

## 使用方式

```python
import joblib

bundle = joblib.load("rag_tfidf_index_v1.joblib")
vectorizer = bundle["vectorizer"]
matrix = bundle["matrix"]
records = bundle["records"]
query = "进程调度算法"
vec = vectorizer.transform([query])
scores = (matrix @ vec.T).toarray().ravel()
top = sorted(range(len(records)), key=lambda i: scores[i], reverse=True)[:5]
```

## 说明

1. 本周索引只用于检索演示和后续 RAG，不用于最终语义相似度评测。
2. 100 条语料来自无图、单选、有答案、带难度和 Bloom 层级的种子题。
3. 2026 年题未参与索引。
