### 单题问题代码

- `A1` 答案错误或无唯一正确答案
- `A2` “最佳答案”存在争议
- `Q1` 题干或选项表述有歧义
- `Q2` 计算条件、图表或单位缺失
- `K1` 知识点不匹配
- `K2` 概念或事实错误
- `D1` 干扰项不具迷惑性
- `D2` 干扰项不对应典型误解
- `T1` 难度与目标明显不符
- `T2` Bloom 层级与目标明显不符
- `C1` 与现有题目重复
- `S1` 隐私、安全或不当内容
- `X1` 其他，需在文字意见中说明

## C. 评分锚点

### C1 答案正确性

| 分数 | 判定 |
|---:|---|
| 5 | 答案与解析完整、正确、唯一，无明显争议 |
| 4 | 答案正确，解析存在小遗漏但不影响作答 |
| 3 | 答案基本正确，但需补充限制或修改解析 |
| 2 | 存在多解、边界未定义或答案可疑 |
| 1 | 答案错误或无法确定唯一答案 |

### C2 题意清晰度

| 分数 | 判定 |
|---:|---|
| 5 | 无需修改即可直接用于正式试卷 |
| 4 | 仅需文字润色 |
| 3 | 需要局部补充条件或调整选项 |
| 2 | 多处歧义，需重写 |
| 1 | 无法明确理解题目要求 |

### C3 知识准确性

| 分数 | 判定 |
|---:|---|
| 5 | 概念、术语、符号和计算结果均准确 |
| 4 | 主体正确，有小瑕疵但不误导 |
| 3 | 存在需要教师修正的知识偏差 |
| 2 | 会明显误导学生的概念或计算错误 |
| 1 | 核心知识错误 |

### C4 干扰项合理性

| 分数 | 判定 |
|---:|---|
| 5 | 所有错误项均对应典型误解且具有适度迷惑性 |
| 4 | 大部分干扰项合理，个别较弱 |
| 3 | 至少一半干扰项有教学诊断价值 |
| 2 | 干扰项多为随意拼凑或明显荒谬 |
| 1 | 无法形成有效干扰 |

### C5 教学价值

| 分数 | 判定 |
|---:|---|
| 5 | 精准考查核心知识点，可用于诊断 |
| 4 | 有较好的练习和迁移价值 |
| 3 | 可用，但价值一般 |
| 2 | 偏记忆或机械，诊断价值低 |
| 1 | 不值得进入题库 |

### C6 教师难度

| 分数 | 判定 |
|---:|---|
| 1 | 基础识记，多数学生可快速完成 |
| 2 | 基本理解，少量计算或辨析 |
| 3 | 需要多步推理或综合两个知识点 |
| 4 | 复杂综合，易出现计算或逻辑错误 |
| 5 | 高难综合或设计题，需要完整方案 |

### C7 Bloom 层级

建议只选择一个主层级：`记忆 / 理解 / 应用 / 分析 / 评价 / 创造`。如果题目跨越多个层级，以完成作答所需最高层级为主。

## F. 数据使用与保密

- 评审者以匿名编号进入实验数据，不公开姓名、联系方式或任教单位。
- 试题若来自受限资源，不进入公开附录或演示视频。
- 报告只呈现统计结果和经过授权的脱敏示例。
- 模型预测结果不得在评卷前展示，避免锚定效应。
- 教师评分与系统输出必须分开保存，便于计算相关性。
